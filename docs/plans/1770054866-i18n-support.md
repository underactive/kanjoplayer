# i18n Support for KanjoPlayer

## Overview

Add internationalization (i18n) support that ships English defaults while allowing users to provide their own string maps. This follows the library's existing configuration pattern (deep merge with defaults).

## Approach: English Defaults + User-Provided Strings

- **Zero config for English users** - works out of the box
- **User-provided locales supported** - full or partial string overrides
- **Runtime locale switching** - change language without recreating player
- **Type-safe** - TypeScript catches missing/misspelled keys
- **Minimal bundle impact** - ~3KB for English defaults + LocaleManager

## Strings to Localize (~80 strings)

| Category | Examples |
|----------|----------|
| Play/Pause | "Play (Space)", "Pause (Space)", aria-labels |

## Implementation Plan

### Phase 1: Create i18n Infrastructure

**New files:**
```
packages/kanjo-player/src/i18n/
  index.ts              # Exports
  types.ts              # LocaleStrings interface
  LocaleManager.ts      # String access with interpolation
  en.ts                 # Default English strings
```

**`types.ts`** - Define all string keys with dot notation:
```typescript
export interface LocaleStrings {
  'play.tooltip': string;           // "Play (Space)"
  'play.ariaLabel': string;         // "Play"
  'skip.backTooltip': string;       // "Skip back {duration}s"
  // ... ~80 keys total
}

export interface LocaleInterpolations {
  'skip.backTooltip': { duration: number };
  'loop.tooLong': { duration: number; max: number };
  // Keys that need interpolation values
}
```

**`LocaleManager.ts`** - Class for string access with runtime switching:
```typescript
export class LocaleManager {
  private strings: LocaleStrings;
  private listeners: Set<() => void> = new Set();

  constructor(customStrings?: Partial<LocaleStrings>) {
    this.strings = { ...en, ...customStrings };
  }

  get<K extends keyof LocaleStrings>(key: K): string {
    return this.strings[key];
  }

  t<K extends keyof LocaleInterpolations>(key: K, values: LocaleInterpolations[K]): string {
    return interpolate(this.strings[key], values);
  }

  // Runtime locale switching
  update(newStrings: Partial<LocaleStrings>): void {
    this.strings = { ...en, ...newStrings };
    this.listeners.forEach((listener) => listener());
  }

  // Subscribe to locale changes (for UI re-renders)
  onChange(listener: () => void): () => void {
    this.listeners.add(listener);
    return () => this.listeners.delete(listener);
  }
}
```

### Phase 3: Update UI Components

Replace hardcoded strings in each control. Pattern:

**Before:**
```typescript
btn.title = 'Play (Space)';
btn.setAttribute('aria-label', 'Play');
```

**After:**
```typescript
const locale = this.player.locale;
btn.title = locale.get('play.tooltip');
btn.setAttribute('aria-label', locale.get('play.ariaLabel'));
```

**With interpolation:**
```typescript
btn.title = locale.t('skip.backTooltip', { duration: 10 }); // "Skip back 10s"
```

### Phase 4: UI Components Subscribe to Locale Changes

Each UI component subscribes to locale changes for runtime switching:

```typescript
export class PlayButton {
  private unsubscribeLocale?: () => void;

  constructor(player: KanjoPlayerAPI) {
    // Initial render
    this.updateStrings();

    // Subscribe to locale changes
    this.unsubscribeLocale = player.locale.onChange(() => this.updateStrings());
  }

  private updateStrings(): void {
    const locale = this.player.locale;
    this.element.title = locale.get('play.tooltip');
    // ...
  }

  destroy(): void {
    this.unsubscribeLocale?.();
  }
}
```

## User API

```typescript
import { KanjoPlayer, defaultLocale } from 'kanjo-player';
import type { LocaleStrings } from 'kanjo-player';

// English (default) - no config needed
const player = new KanjoPlayer({ container: '#player', src: 'video.mp4' });

// Partial override (custom strings merged with English)
const player = new KanjoPlayer({
  container: '#player',
  src: 'video.mp4',
  locale: {
    'play.tooltip': 'Start Video',
    'pause.tooltip': 'Stop Video',
  },
});

// User-provided full locale (e.g., Spanish)
const spanishLocale: LocaleStrings = {
  'play.tooltip': 'Reproducir (Espacio)',
  'play.ariaLabel': 'Reproducir',
  'pause.tooltip': 'Pausar (Espacio)',
  // ... all ~80 keys
};
const player = new KanjoPlayer({
  container: '#player',
  locale: spanishLocale,
});

// Runtime locale switching
player.locale.update(spanishLocale); // Switch to Spanish
player.locale.update({}); // Switch back to English (empty = defaults)
```
