# i18n Support Implementation

**Plan:** `docs/plans/1770054866-i18n-support.md`
**Implemented:** 2026-02-02

## Summary

Implemented full internationalization (i18n) support for KanjoPlayer with:
- Zero-config English defaults
- 6 bundled locales (en, es, fr, de, ja, zh)
- User-provided locale overrides (full or partial)
- Runtime locale switching without recreating the player
- Type-safe string keys with TypeScript

## API

### Basic Usage (English default)

```typescript
const player = new KanjoPlayer({
  container: '#player',
  src: 'video.mp4',
});
```

### Using Bundled Locale

```typescript
import { KanjoPlayer, locales } from 'kanjo-player';

const player = new KanjoPlayer({
  container: '#player',
  src: 'video.mp4',
  locale: locales.es, // Spanish
});
```

### Partial Override

```typescript
const player = new KanjoPlayer({
  container: '#player',
  src: 'video.mp4',
  locale: {
    'play.tooltip': 'Start Video',
    'pause.tooltip': 'Stop Video',
  },
});
```

### Runtime Locale Switching

```typescript
// Switch to French
player.locale.update(locales.fr);

// Switch back to English
player.locale.update(locales.en);

// Partial update (merged with current strings)
player.locale.update({ 'play.tooltip': 'Custom Play' });
```

### String Interpolation

Strings with placeholders use `{placeholder}` syntax:

```typescript
// In locale file:
'skip.back': 'Skip back {duration}s'

// Usage:
locale.t('skip.back', { duration: 10 }); // "Skip back 10s"
```

## LocaleManager Class

```typescript
class LocaleManager {
  // Get a simple string
  get<K extends keyof LocaleStrings>(key: K): string;

  // Get a string with interpolation
  t<K extends keyof LocaleStrings>(key: K, values: Record<string, string | number>): string;

  // Update locale (triggers all subscribers)
  update(newStrings: Partial<LocaleStrings>): void;

  // Subscribe to locale changes (returns unsubscribe function)
  onChange(listener: () => void): () => void;
}
```

## Deviations from Plan

1. **DownloadOverlay handling**: The plan didn't account for DownloadOverlay not having direct player access. Solved by adding `setLocaleManager()` method called from ControlsOverlay.

2. **SimpleStringKey type**: Added helper type for non-interpolated string keys to improve type safety in the `get()` method.

3. **Default locale in options**: Added `locale: {}` as default in `mergeOptions()` to satisfy TypeScript's `Required<KanjoPlayerOptions>` type.

The 6 bundled locales add approximately 18KB to the bundle (uncompressed). Users who only need English can tree-shake unused locales by not importing them.
